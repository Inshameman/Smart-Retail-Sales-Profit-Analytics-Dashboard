# 📊 Smart Retail Sales & Profit Analytics Dashboard | Power BI

## 📌 Project Overview

The **Smart Retail Sales & Profit Analytics Dashboard** is an interactive business intelligence project developed using Microsoft Power BI to analyze retail sales performance, profitability, product performance, and customer purchasing trends.

The dashboard transforms raw retail transaction data into meaningful business insights through interactive visualizations, KPIs, and dynamic filters. It helps businesses monitor performance, identify sales trends, understand profitability, and make data-driven decisions.

## 🎯 Project Objectives

- Monitor overall sales and profit performance.
- Analyze monthly sales trends.
- Identify top-performing products.
- Evaluate category-wise sales and profitability.
- Compare sales performance across different sales channels.
- Analyze the impact of discounts on sales and profit.
- Provide interactive filters for exploring business insights.

## 📈 Dashboard Features & KPIs

The dashboard includes the following key performance indicators and visualizations:

### Key Performance Indicators (KPIs)
- 💰 Total Sales
- 💵 Total Profit
- 📦 Total Quantity Sold
- 🛒 Total Orders
- 🎯 Average Discount

### Data Visualizations
- Monthly Sales Trend
- Sales by Category
- Top 5 Products by Sales
- Sales by Sale Type
- Profit by Category

### Interactive Filters (Slicers)
- Sale Type
- Payment Mode
- Month

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and KPI development.
- **Microsoft Excel** – Dataset preparation and data analysis.

## 📂 Dataset Description

The project uses a retail sales transaction dataset containing the following fields:

- Sales Transactions
- Product Details
- Categories
- Quantity
- Selling Price
- Buying Price
- Discount Percentage
- Payment Mode
- Sale Type
- Date

## 🔍 Business Insights

This dashboard helps answer important business questions:

1. What is the overall sales and profit performance?
2. Which months generate the highest sales?
3. Which products contribute the most to total sales?
4. Which product categories generate the highest profit?
5. Which sales channels perform better?
6. How do discounts affect sales and profitability?
7. Which payment methods are commonly used?
